# WDI 2026 — laboratoria

## Zasady oceniania

Laboratoria obejmują 11 spotkań stacjonarnych w sali laboratoryjnej. Każde spotkanie trwa 2 × 45 minut.

- **Spotkania 1–9:** do każdego przypisany jest zestaw zadań do samodzielnego rozwiązania. Za zestaw oddany przed kolejnymi zajęciami można otrzymać od 0 do 5 punktów, a za oddany po terminie — od 0 do 3 punktów.
- **Spotkania 2–9:** każde rozpoczyna się dziesięciominutową pisemną wejściówką, za którą można otrzymać od 0 do 5 punktów.
- **Spotkanie 10:** pisemne kolokwium teoretyczno-praktyczne trwające 45 minut. Pozostała część spotkania jest przeznaczona na indywidualne odpowiedzi ustne.
- **Spotkanie 11:** kontynuacja indywidualnych odpowiedzi ustnych.

Podczas odpowiedzi ustnej student rozwiązuje zadanie programistyczne w obecności prowadzącego, korzystając ze środowiska bez podpowiedzi składni.

Oceny z wejściówek, zadań, kolokwium i odpowiedzi ustnej są wystawiane osobno. Przy ustalaniu oceny końcowej stosuje się następujące wagi:

| Element | Waga |
| --- | ---: |
| Wejściówki | 2 |
| Zestawy zadań | 1 |
| Kolokwium | 3 |
| Odpowiedź ustna | 2 |

Warunkiem zaliczenia laboratoriów jest uzyskanie oceny pozytywnej z każdego z czterech elementów.

**Wejściówki:** ocena wynika z sumy punktów uzyskanych na spotkaniach 2–9 (maksymalnie 40 punktów).

| Suma punktów | Ocena |
| --- | ---: |
| 0–20 | 2 |
| 21–27 | 3 |
| 28–31 | 3,5 |
| 32–34 | 4 |
| 35–37 | 4,5 |
| 38–40 | 5 |

**Zadania:** ocena wynika z sumy punktów za zestawy przypisane do spotkań 1–9 (maksymalnie 45 punktów).

| Suma punktów | Ocena |
| --- | ---: |
| 0–22 | 2 |
| 23–29 | 3 |
| 30–33 | 3,5 |
| 34–37 | 4 |
| 38–41 | 4,5 |
| 42–45 | 5 |

## Sposób rozliczania zadań

Foldery `01`–`09` odpowiadają spotkaniom, do których przypisano zestawy zadań. Treść każdego opublikowanego zestawu znajduje się w pliku `zadania.md`. Rozwiązania należy umieszczać w podfolderach poszczególnych zadań jako pliki źródłowe C (`.c` oraz, jeśli są potrzebne, `.h`), na przykład `main.c`.

Zestawy na kolejne spotkania mogą ulec zmianie przed rozpoczęciem tych zajęć. Z tego powodu nie zaleca się rozwiązywania zadań z wyprzedzeniem.

1. Utwórz fork [repozytorium kursu](https://github.com/WDI-WDP/WDI-2026) na swoim koncie GitHub i wyślij prowadzącemu e-mailem link do tego forka.
2. Przed rozpoczęciem pracy nad zestawem podczas zajęć sprawdź, czy Twój fork wymaga synchronizacji z repozytorium kursu. Jeśli tak, zsynchronizuj go i zaktualizuj lokalną kopię repozytorium.
3. Umieść rozwiązania w odpowiednich podfolderach, zapisz zmiany w lokalnym repozytorium i wyślij je do swojego forka na GitHub.

Przy ocenie liczy się stan forka dostępny online w terminie oddania zestawu. Zmiany pozostające wyłącznie na komputerze studenta nie są uwzględniane.

Podczas spotkań 2–9 prowadzący może sprawdzić samodzielność wykonania przesłanych rozwiązań. W razie wątpliwości może poprosić studenta o ich ustne wyjaśnienie.

## Obecność

Obecność na zajęciach jest obowiązkowa. Usprawiedliwioną nieobecność należy odrobić w porozumieniu z prowadzącym.

Nieobecność nie przesuwa terminu oddania zestawu zadań. Za wejściówkę na opuszczonym spotkaniu 2–9 student otrzymuje 0 punktów. W przypadku usprawiedliwionej nieobecności może odrobić wejściówkę w trybie ustalonym indywidualnie z prowadzącym.
